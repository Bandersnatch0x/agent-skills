## 何时使用

- 谱已在手,要把谱切成可执行票(含阻塞边)。
- 已有票需要重切(粒度不对、阻塞边错、该合该拆)。
- 不适用:谱还没有 → 走成谱。

## 怎么用

1. **读谱与缝**。谱是唯一权威;缝(测试边界)已在谱的「测试决策」节。
2. **切票**。每票一条**窄而完整的贯穿切片**:穿过每一层(schema / 接口 / 界面 / 测试),
   切完能**独立演示或验证**,单张票塞得进一个全新上下文窗;**垂直切片而非某一层的水平切片**。
   预重构(先让改动变容易)一律先行成票。
3. **宽带重构走三段**:一次机械改动的爆炸半径横跨全仓、任何垂直切片都无法单独保绿时,
   改走 expand(新形式旁挂旧形式,什么都不破)→ migrate(调用点按爆炸半径分批,每批一票,被 expand 阻塞)→
   contract(旧形式无调用者后删除,被全部 migrate 批阻塞)。批次不能单独保绿时,保留序列但共享一条集成分支,
   共同阻塞一张「集成并验证」票,**绿只在那里承诺**。
4. **每票写四行**:标题 / 上游谱指针 / 这张票交付的**端到端行为** / 阻塞边(无则显式写「无阻塞」);
   再加「消费 / 产出」接口块两行——相邻票所用的名字与类型只在这里能得到对齐,
   执行者只看得到自己那一票。
5. **拷问用户,不直接发布**。把拆解编号列出(标题 / 阻塞边 / 端到端交付什么),
   问三件事:**粒度对不对?阻塞边对不对(是否只依赖真正卡住它的票)?有没有该合该拆的?**
   迭代到用户批准才发布。
6. **发布**:按本仓 tracker 惯例建票(先建全部票→再连阻塞边,两遍),谱票只被引用、不改不关。

## 边界

- **不关闭也不修改谱票**。
- **不自行开工**:本技能只出票,落码由流水线下一阶段接手。
- **个人事项不进正式 tracker**:个人待办与个人票据记录留本地个人面;只有项目级共享工作才在正式 tracker 建票(口径见票据惯例的「个人面与项目面」)。
- 不重写谱的口径:谱与拆解冲突时停下来问用户,不擅自改谱。
- 票不从雾里切:只切谱已钉下的内容;谱未覆盖的留缺口清单,交回成谱或拷问。
